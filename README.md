# 은방울 관리일지

《판매왕, 제국을 털다》의 관리원 배치 퍼즐. 이 폴더가 웹앱 전체다.

## 올리는 법

- GitHub Pages: 이 폴더의 파일을 저장소 맨 위에 올리고, Settings → Pages에서 main 브랜치를 고른다.
- 그 밖의 정적 호스팅(Netlify, Cloudflare Pages 등): 이 폴더를 통째로 올린다. 빌드 과정은 없다.

https 주소로 열어야 설치(홈 화면에 추가)와 오프라인 실행이 된다.

## 고칠 때

index.html을 바꾸면 sw.js의 CACHE 이름도 바꿔야 기기에 새 판이 내려간다.
